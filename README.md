## 📌 Context & Problem Statement
Beep has grown to over 1M+ users across India, bringing career pathways to students in Tier-2 and Tier-3 colleges. However, an in-depth audit of user reviews on the Google Play Store (`com.eventbeep.android`) and Apple App Store highlights the 3 biggest problems students face:

1. **The "Dead-End Certificate" & Proof-of-Work Void:**  
   Students clear timed multiple-choice assessments and earn digital certificate badges, but **less than 4.2% convert into actual startup interviews**. Startups reject freshers whose resumes only feature generic classroom projects (*"Library Management System"*, *"ToDo App in React"*).
2. **The Vernacular Freeze & 5-Minute Screening Anxiety:**  
   Students outside metro tier-1 colleges often possess technical capability, but suffer paralyzing anxiety when speaking English in Google Meet or telephonic screening rounds. Over 62% fail the first 5 minutes.
3. **The Cold Application Black Hole & Day-7 Churn:**  
   Students send generic cover letters (*"Respected Sir, please find attached resume"*) with <1.5% recruiter response rates, leading to steep Day-7 app abandonment.

---

## 💡 The Solution: Beep CareerCopilot
A lightweight, high-performance web application designed to integrate directly with Beep's core product:

* 🎙️ **Interactive AI Mock Interviewer:** Real-time Indian English speech-to-text (`webkitSpeechRecognition`), instant STAR framework scoring (0-100), filler word detection, and a toggleable **"Hinglish Coach Mode"** providing culturally empathetic advice.
* 🛠️ **Proof-of-Work Project Architect:** Ingests generic college projects and transforms them into 10x distributed systems architecture with 48-hour sprint roadmaps, copyable boilerplate code, and 3 ATS-optimized resume bullet points.
* 🚀 **Founder Cold Outreach Studio:** Converts generic resumes into high-converting 3-sentence value-first outreach pitches for LinkedIn, Twitter, and cold email.
* 📊 **Beep Audit & 7-Day Metric Engine:** Complete breakdown of the 3 problems with proof, alongside an A/B test blueprint targeting a **3.5x lift in 7-day interview conversion (4.2% ➔ 14.8%)**.

---

## 🛠️ Technology Stack
* **Frontend Framework:** React 19 + Vite 5 (Fast, lightweight bundle < 100kB gzipped)
* **Styling:** Custom Vanilla CSS Design System with dark mode glassmorphism and modern design tokens
* **Speech Intelligence:** Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`) with `en-IN` acoustic modeling
* **AI Evaluation Engine:** Google Gemini 1.5 Flash API with intelligent local heuristic fallback (100% uptime with or without an API key)
* **Icons & Animation:** `lucide-react`, `canvas-confetti`
* **Deployment & CI/CD:** Automated GitHub Pages edge deployment pipeline via GitHub CLI (`gh`)
